# 🐍 Snake Game using React Hooks

This project is a simple but fun implementation of the classic Snake Game built using **React** and **React Hooks**.

It was developed as part of an assessment task to demonstrate my understanding of functional components and hooks like `useState` and `useEffect`.

---

## 🎮 Features

- Snake movement using arrow keys
- Collision detection (walls & self)
- Game over screen
- Score tracking
- Responsive layout using CSS

---

## 🔧 Tech Stack

- React
- JavaScript (ES6)
- HTML & CSS
- useState / useEffect Hooks
